Build a unified knowledge layer for Agents with Foundry IQ Phi Huynh
Running AI agents in enterprise is not just about picking the right LLM. The hard part is giving them the right context. In this session, I will show how Foundry IQ helps your agents pull knowledge from where your data actually lives, SharePoint, OneLake, Azure Blob Storage, Azure AI Search, the web, and even MCP servers and more...
11:15 AM - 12:00 PM
Build an Agent Harness with Microsoft Agent Framework and GitHub Copilot SDK Thang Chung
Most agent demos stop at a prompt and a response. Real systems need much more: session isolation, channel adapters, tool orchestration, memory, operational boundaries, and a clean way to connect model runtime to business capabilities. In this talk, I will break down how a reference agent harness uses Microsoft Agent Framework and GitHub Copilot SDK, and .NET Aspire as the operational layer around the harness. The focus is not just on calling an LLM, but on building a reusable agent harness that can survive real conversations, real tools, and real deployment concerns.
